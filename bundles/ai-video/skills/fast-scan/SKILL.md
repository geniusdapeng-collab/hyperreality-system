# 账号快照快扫（快速体检）

## 〇、定位

「先体检，再托管」客户旅程的**第一公里**：客户坐在现场，授权社媒账号后 15–30 分钟拿到《账号快速体检报告》——"原来我的账号每月在漏这些粉和线索"。这是购买决策的催化剂，也是质检模式（audit_only）的旗舰技能。

与持续观察的分工：
- **本技能（快照快扫）**：基于历史数据快照的存量问题，15–30 分钟一遍过——权重信号/限流痕迹/断更节律/低效选题/存量负面/高意向咨询遗漏/转化组件缺失。
- **持续观察（账号经营管线 account-ops，1–2 周）**：需要时间才能观察的问题——流量曲线实测、评论响应时长、发布窗口效果、趋势与峰值行为。

## 一、何时调用

- 售前演示：客户现场授权 1–N 个社媒账号后立即触发（目标：当场出报告）。
- 新客户接入质检模式时自动执行一次（基线快照），此后转入持续观察。
- 客户手动触发"重新体检"（如大促campaign后/整改后复查对比）。

## 二、输入契约

- 连接器只读快照（平台只读 scope 授权，全程不触发任何写接口）：
  - 内容数据（近 90 天：发布记录/播放/完播/点赞/评论/分享/收藏）
  - 评论与私信（存量未回复评论/负面与咨询标记/私信会话与响应状态）
  - 粉丝数据（粉丝量曲线/画像/取关异常波动）
  - 转化数据（主页组件/挂载链接/团购或线索表单/转化点击）
  - 账号状态（违规记录/限流信号/权重相关公开指标）
- 账号档案（平台/类目/内容定位/转化目标，缺失时用类目基准值并在报告中标注"按类目基准估算"）。
- 时间预算参数：默认 30 分钟硬上限（超时出部分报告并标注覆盖度）。

## 三、执行步骤（四线静态分析，一遍过）

1. **快照拉取与口径校准**（≤5 分钟）：动作=各平台连接器只读拉取，归一化为统一数据模型（跨平台字段映射）；产出物=快照数据集+覆盖度清单；回执=各源拉取回执（行数/时间窗/完整率）。
2. **账号健康线**：动作=权重信号盘点（粉丝活跃度/互动率 vs 类目基准）→ 限流风险识别（播放量断崖/搜索不可见痕迹/发布即低推荐）→ 违规与处罚记录归集 → 账号安全（异常登录/防关联风险，G16 域只读核查）；产出物=账号健康清单（含风险等级与处置建议）；回执=计算过程快照。
3. **内容健康线**：动作=发布节律分析（断更天数/频率波动/高峰窗口错配）→ 低效选题盘点（持续低于账号均值的选题方向）→ 高潜素材挖掘（历史高完播/高互动但未复用、未二剪、未跨平台分发的内容）；产出物=内容问题清单+高潜素材复用单（**每项标注预估涨粉/播放提升，含口径**）；回执=计算过程快照。
4. **评论与口碑线**：动作=存量未处理负面评论（>48h 清单）→ 高意向咨询遗漏（问价/求链接/怎么买类未回复）→ 敏感词与合规风险扫描（极限词/平台违禁词/舆情苗头）；产出物=口碑风险清单+线索挽回单（**每条高意向咨询标注线索流失估算**）；回执=扫描回执。
5. **转化健康线**：动作=主页转化组件核查（联系方式/商品橱窗/团购/预约组件缺失）→ 私信响应健康（未读未回/响应超时会话占比）→ 转化链路断点（内容高流量但主页零转化承接）；产出物=转化健康清单（含线索流失点定位与估算）；回执=计算过程快照。
6. **汇总成报告**：动作=四线结果按预估涨粉/线索挽回排序 → 每条附"问题+证据+建议动作+估算收益与口径" → 汇总一账号一份《账号快速体检报告》+ 矩阵总览（Top10 行动清单）；产出物=报告卡片（IM 触达+工作台可查）；回执=报告事件 ID 与触达回执。

## 四、边界与围栏

- **全程只读**：audit-only patch 生效——发布/回评论/私信/改简介/投放一切平台写操作物理 block；本技能只向系统事件库写入发现与报告。
- **估算口径透明**：所有"预估涨粉/线索挽回"标注计算口径与置信度（精确值/按类目基准估算/经验估计），禁止把估算说成确定值。
- **时间纪律**：30 分钟硬上限；某数据源超时→该线标注"未覆盖"并降级出部分报告，不阻塞整体。
- 不做什么：不做趋势预测（需观察期数据）、不做响应时长实测（需在线观察）、不做任何处置动作（只出建议，整改由客户在平台侧人工执行）。

## 五、与其他技能的协作

- 产出 → 账号经营管线 `account-ops`（持续观察接管：metrics-watcher 定时采集验证快扫发现，监测时变问题）
- 产出 → `comment-ops`（体检发现的存量负面/高意向咨询并入评论分流队列，候选草稿待客户拍板）
- 产出 → `jenny-loom-research`（高潜素材与竞对空位转入情报五站深挖选题）
- 报告中的整改项被客户确认后 → 对应域技能生成执行草案（影子模式起）
- 复查场景：与上次报告 diff，产出《整改闭环率》对比卡

## 六、验收用例

- 接入含已知断更与未回复负面的演示账号，30 分钟内产出报告且该问题出现在对应线清单（含证据与建议动作）。
- 报告中每条估算收益均带口径标注；任一数据源缺失时报告正常产出且对应线标注"未覆盖"。
- 全程事件库无任何平台写操作记录（RuleImpact 全为只读动作）。
