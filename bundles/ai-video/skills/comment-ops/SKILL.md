# 评论三级分流 SOP

## 适用场景
- 账号经营管线评论采集与回复外发（G10 分流门）
- 负面/危机评论的告警与人工接管

## 方法
1. 采集与分类：每 30 分钟采集评论，意图分类为 praise/thanks/consult/after_sale/negative/crisis/sensitive。
2. 三级分流：
   - 夸赞/感谢 → auto 自动回（仅限模板库内措辞，不即兴发挥）；
   - 咨询/售后 → review 审批后回，复杂售后转人工；
   - 负面/危机 → review + 告警；含投诉/维权/退款/骗子/举报关键词必走此档；
   - 政治敏感等 → block，只写「需介入」事件（L4.2 不确定不执行）。
3. 候选回复须附依据：引用评论原文 + 相关档案/商品条目。
4. 外发回执落账；发送失败即转人工，不重复发送。

## 输出契约
- 每条评论输出：意图标签 + 分流级别 + 候选回复（含依据）+ 外发回执。
- auto 档外发内容必须可回溯到模板编号。
- 无工具回执的关键数字标「未核实」，不得宣称完成（L3.6/E3.7）。
