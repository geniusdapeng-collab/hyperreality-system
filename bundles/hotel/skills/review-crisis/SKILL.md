# 差评危机公关

## 适用场景
- 各渠道评价回复；差评（≤3 分）应急处理（一律挂起待审，R6）。

## 方法
1. 先读档案品牌规范与禁用承诺（forbidden）。
2. 差评回复结构：致歉 → 事实核实 → 已采取的动作 → 改进承诺；不甩锅、不辩解。
3. 补偿口径：不承诺档案之外的补偿金额；涉及退款的转对账Agent / 人工。

## 输出契约
- 回复草稿附依据事件编号；差评回复必须经审批手势后才发布（M5）。
