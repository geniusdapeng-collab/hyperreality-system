# 跨平台统一复盘 SOP

## 适用场景
- 周度跨平台内容复盘（抖音/小红书/B站/视频号/TikTok/YouTube）
- 爆款复制与扑街规避的归因分析
- 选题池与内容日历的复盘驱动调整建议

## 方法
1. 口径对齐：播放/完播/互动/转化统一标准口径；平台原生口径差异（如 B站完播 vs 抖音完播）必须先声明再入对比表。
2. 双向归因：
   - Top3 爆款：拆做对了什么——题材、前 3 秒钩子、发布时段、平台流量机制、封面标题；
   - Flop3 扑街：拆做错了什么——同维度对照，给出与爆款的差异点。
3. 可执行结论：每条结论落到「下一条做什么/不做什么」，禁只报数据不判断；结论回写选题卡（topic_card）供排期引用。
4. 低置信纪律：单平台样本 <5 条或周期 <7 天，结论标「低置信」，不下强结论。

## 输出契约
- 周复盘报告：口径对齐说明 + Top3/Flop3 归因表 + 可执行结论清单（每条挂题材/钩子/时段标签）。
- 所有对比数字可回溯到 account_metric 原始快照；无工具回执的关键数字标「未核实」。
- 报告为内部产物：不擅自改排期/停内容/回评论，调整建议以报告形式提交主理人。
