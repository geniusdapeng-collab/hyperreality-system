# 拉片反推（ripping-reverse · jenny-loom-research v2）

## 适用场景
- 竞品/爆款视频的工艺逆向：搞清楚「这条为什么跑得好、怎么拍出来的」
- 为选题会提供可复用的分镜结构与提示词资产
- 工艺技能库（library）的行业案例扩充

## 输入
- 爆款视频文件或链接（须为公开内容，附来源 URL 与平台）
- 可选：该视频的公开数据快照（播放/点赞/评论量级），用于校准「值得拆」

## 触发
- 人工发起：上传视频并指定拆解深度（快速 6 维 / 完整 18 维）
- 半自动：trend-researcher 扫描到同垂类爆款超阈值时，产出「建议拉片」选题卡，人工确认后启动

## 方法（18 维拆解）
1. 景别（4 维）：景别序列、特写占比、景别切换频率、信息密度/镜头。
2. 运镜（4 维）：运镜类型分布（推/拉/摇/移/跟/手持）、运动速度曲线、稳定器 vs 手持风格、转场方式。
3. 叙事结构（4 维）：钩子类型与前 3 秒拆解、段落起承转合、信息释放节奏（悬念/反转点位置）、CTA 位置与形式。
4. 节奏（3 维）：镜头平均时长、剪辑点密度曲线、声画对位（卡点/反打）。
5. 色彩（3 维）：主色调与配色方案、对比度/饱和度风格、光影基调（高调/低调/胶片感）。
6. 反推合成：18 维结论 → 分镜结构表（镜号/景别/运镜/时长/画面描述/台词钩子）→ 提示词包草稿（对齐 25/30 字段口径）。

## 输出契约
- 18 维拆解报告：每维度附时间码证据（[mm:ss] 引用），无证据的结论标「推断」。
- 分镜结构表 + 提示词包草稿：入技能库前必过 G2（主题/Brief 确认）与 G6（提示词审核）——拉片产物是研究资产，跳过确认门直接进生产即违规。
- 入库命名：拉片_平台_题材_日期，链回来源 URL 与数据快照。

## 边界
- 只拆公开内容，不破解/不抓取非公开或付费墙内容。
- 反推产物为「工艺学习」，禁止像素级复刻他人作品直接商用；版权边界问题转 ip-curator 校验。
- 与 G2 的关系：拆解报告本身 auto，但任何「按反推结果立项/出提示词包进渲染」的动作必须过 G2 必审，确认题材与品牌口径自洽后方可流转 G6。
