# 快速上线模式 · 行业Bundle骨架模板

> 用途：落地向导"快速上线模式"的内置模板。跳过深度调研，用本骨架快速生成可激活的行业Bundle草稿，上线后再按需补跑深度调研（技能一/二）迭代完善。
> 用法：将 `<行业>` 占位替换为目标行业，按各行业域填写。所有阈值均为**保守默认**，客户只可收紧。

## 1. 行业定义卡

| 项 | 内容 |
|----|------|
| 行业名称 | `<行业>`（如：餐饮/美业/教培） |
| 目标客群 | `<中小单体业态描述>` |
| 一线角色 | 经营负责人 / 客户接触一线 / 服务交付一线 |
| 经营对象枚举（objects） | 商品或服务项 / 价格 / 渠道 / 订单 / 客户 / 评价 / 门店 / 员工（8类基线，可扩展） |
| 经营阶段（stages） | 爬坡期 / 稳定期 / 旺季 / 淡季 / 调整期（门店级基线，可扩展客户级与运营级） |

## 2. Agent班组基线（7角色映射）

| 角色 | 职责 | 围栏绑定 |
|------|------|----------|
| pricing-agent | 定价与收益 | R1涨幅上限 auto / R2保底价 block |
| review-agent | 评价与客服 | R6差评必审 |
| reconcile-agent | 对账与结算 | R4大额退款必审 / R5异常 block |
| inspection-agent | 只读巡检 | 只读 preset（L9.1） |
| content-agent | 内容与客户运营 | R3新渠道首发必审 |
| competitor-agent | 竞对监控 | 只读+频次自律 |
| desktop-agent | 无API系统GUI兜底 | high_risk=true，逐次授权 |

## 3. 围栏基线模板

| 规则 | 默认阈值（保守） | 级别 |
|------|------------------|------|
| R1 价格单日涨幅自动上限 | ≤8% | auto |
| R2 保底价熔断 | `<行业保底价>` | block |
| R3 新渠道首次改价/发布 | 必审 | review |
| R4 大额退款 | ≥`<行业退款阈值>` 必审 | review |
| R5 订单/担保异常 | 只写需介入 | block |
| R6 差评 | 必审 | review |

## 4. 一店一档最小字段（激活必需）

基础档案（名称/地址/规模）+ 业务档案（对象清单/阶段/目标）+ 治理档案（围栏确认记录/forbidden禁用承诺）。先可激活、再求完备（二期渐进补齐运营档案与记忆档案）。

## 5. 夜班与决策包默认

夜班窗口 22:00-08:00（谷时费率），08:30 清晨决策包（已完成/待审批/需介入三栏），一键暂停 ≤60s。
