# 商单全流程 SOP

## 适用场景
- 商单线索承接与报价谈判（品牌直客/平台商机/达人合作报价）
- 商单履约跟踪与账期管理
- 结案复盘与复购线索挖掘

## 方法
1. 线索捕获：私信/邮件/平台商机统一入 deal_order，24h 内首响，补全客户画像（行业/预算带/决策人/历史合作）。
2. 报价带锚定：三档报价——锚定价（刊例/排期稀缺性支撑）、目标价、底价；报价单附锚定理由。价格在宪章 price_quote_band 内可自决，越带升级。
3. 合同与履约：五节点跟踪——brief 确认 → 初稿 → 终稿 → 发布 → 验收；每节点逾期前 48h 预警，节点产物挂 deal_milestone。
4. 账期催款：到期前 7 天友好提醒；逾期 1/7/15 天三档催款，话术逐级升级但只陈述事实与合同条款。
5. 结案报告：验收完成后 48h 内产出——交付清单/发布数据表现/回款状态/复购建议，过 G15 后外发。

## 输出契约
- 每个 deal_order 输出：客户画像 + 三档报价单（含锚定理由）+ 履约节点表 + 回款状态 + 结案报告。
- 对外文件（quote/contract/closure_report）一律走 G15 审批，审批回执号写入文件落账。
- 低于底价的让步、超授权带的费用承诺，输出「待主理人裁决」事件，不得自行外发。
- 无工具回执的关键数字标「未核实」，不得宣称完成（L3.6/E3.7）。
