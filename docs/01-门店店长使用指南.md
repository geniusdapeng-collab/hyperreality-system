# 门店店长使用指南

> 从下载安装到日常使用，全程不需要任何技术背景。大约 30 分钟即可上手。

---

## 一、下载安装（约 5 分钟）

1. 打开 WorkLoom 官网或 GitHub Releases 页面，下载 **WorkLoom-macOS.zip**。
2. 解压后把 **WorkLoom.app** 拖进「应用程序」文件夹。
3. 第一次打开时，Mac 可能提示「无法验证开发者」。到 **系统设置 → 隐私与安全性**，点一次「仍要打开」即可。**这是整个使用过程中唯一一次需要手动授权的地方。**
4. 双击 WorkLoom.app，启动器会自动完成数据库初始化、服务启动，并打开「工作台」主界面——你什么都不用配。

**电脑要求**：Mac 电脑（M1/M2/M3/M4 芯片），系统 macOS 13 或以上。

## 二、首次配置（约 15 分钟）

第一次进入工作台，按引导完成三步：

1. **录入门店信息**：门店名称、规模、定位、所在城市。这些信息让数码员工了解你的店。
2. **设定经营目标**：比如「本月营收提升 8%」「差评响应不超过 2 小时」。目标会拆解给数码班组去执行。
3. **确认授权范围（围栏）**：系统默认是安全的——**涉及价格调整、对外发送消息等动作，必须经过你批准**；日常巡检、数据整理类动作自动执行。你可以按自己的接受程度调整。

配置完成后，数码班组即刻上岗。

## 三、日常使用（每天 5 分钟）

### 早八点战报

每天早上 8:30，工作台首页会推送一份战报：昨夜发生了什么、指标有没有异常、有没有需要你拍板的事。**大多数早晨，你花 5 分钟看完战报、点几个「同意」，一天的管理动作就完成了。**

### 审批卡片

数码员工遇到需要你决定的事，会以卡片形式发给你：「线上渠道发现 3 笔订单价差，建议调价，同意吗？」你点 **同意** / **驳回** / **改派** 即可。不处理的事不会被执行——钱和客户相关的动作默认要你点头。

### 日常巡检

夜班班组 7×24 小时巡检：差评有没有出现、渠道价格有没有倒挂、满房预测有没有偏差。发现异常会主动 @ 你，并附上建议动作。

### 一键暂停

任何时候你觉得不放心，点工作台右上角的 **紧急制动**，全场数码员工立即停下，控制权回到你手里。黑匣子（事件留痕）会记录一切，随时可以回看谁做了什么。

## 四、常见问题

- **Mac 休眠后还工作吗？** 数码员工运行在这台 Mac 上，休眠会暂停夜班值守。建议插电并关闭自动休眠（系统设置 → 显示器）。
- **数据存在哪里？** 全部存在你自己这台 Mac 的内置数据库里，不上传到任何第三方。
- **坏了怎么办？** 把 WorkLoom.app 退出再打开即可自愈；应用目录下「支持文件」里有完整日志。
