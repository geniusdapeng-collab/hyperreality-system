# WorkLoom 功能清单（用户版）

> 全部功能按使用场景分类，用业务语言描述，不含技术术语。

---

## 场景一：每天的经营掌握

| 功能 | 你能得到什么 |
|---|---|
| 早八点战报 | 每天早上 8:30 推送：昨夜发生了什么、指标异常、待你拍板的事 |
| 经营仪表盘 | 核心指标（营业额、客流、差评数等）实时可视，异常亮红灯 |
| 指标巡检告警 | 指标越过你设定的阈值时主动 @ 你，附建议动作 |

## 场景二：把活派给数码员工

| 功能 | 你能得到什么 |
|---|---|
| 经营目标（Quest） | 用业务语言设定目标（如「本月营收 +8%」），自动拆解成任务 |
| 数码班组 | 一组分工明确的数码员工：收益、渠道、客服、巡检各司其职 |
| 人机混编通讯录 | 人类员工和数码员工在同一个通讯录里，随时查看谁在干什么 |
| 技能沉淀 | 一次好的处置方式可固化为班组技能，下次同类事自动复用 |

## 场景三：审批与控制

| 功能 | 你能得到什么 |
|---|---|
| 审批卡片 | 需要拍板的事以卡片形式送达，一键同意 / 驳回 / 改派 |
| 围栏三级授权 | 每个动作可设为自动执行 / 需要批准 / 禁止，默认偏保守 |
| 一键紧急制动 | 一键暂停全场数码员工，控制权立即回到人手里 |

## 场景四：不打烊的夜班

| 功能 | 你能得到什么 |
|---|---|
| 夜班班组 | 7×24 巡检：差评、价格倒挂、满房偏差，发现即处置或上报 |
| 夜班自动执行 | 设定好的任务夜间照常推进，早上战报汇报结果 |

## 场景五：追溯与问责

| 功能 | 你能得到什么 |
|---|---|
| 黑匣子（事件留痕） | 每一步操作完整留痕：谁发起、谁批准、谁执行、结果如何 |
| 全程可回放 | 任意时间段的操作可回放审查，出了问题能定位到具体一步 |

## 场景六：知识沉淀

| 功能 | 你能得到什么 |
|---|---|
| 组织记忆 | 会话和处置过程沉淀为可检索的企业知识库 |
| 语义搜索 | 用自然语言提问（「上周差评都什么原因」），从历史里找答案 |

## 场景七：部署与数据

| 功能 | 你能得到什么 |
|---|---|
| 一键安装包 | Mac 版一键安装，数据库、服务全自动初始化，无需技术人员 |
| 数据本地存储 | 全部数据存在企业自己的电脑里，不上传第三方 |
| 自动备份 | 数据自动备份，意外中断可恢复 |

---

> 具体某个场景怎么用，见《门店店长使用指南》或《新客户首次接入完整流程》。
