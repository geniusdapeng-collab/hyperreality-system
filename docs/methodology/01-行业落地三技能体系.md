# 行业落地技能体系（方法论）

> WorkLoom 进入任何新行业的标准脚手架：三个调研/设计技能 + 一个交付配置技能，由「行业落地向导」产品化编排执行。
> 技能实物位于 `skills/official/industry-entry/`（official 层，随底座分发，bundle=null）；本文是协作关系与调用契约的说明文档。

## 一、协作关系

```
技能一（竞品调研）──┐
                   ├──→ 技能三（落地方案设计）──→ 技能四（交付配置）──→ WorkLoom行业定制版
技能二（一线调研）──┘         ↑                      ↑
                        WorkLoom底座            客户授权/特有信息
                        （代码摸排为主事实源）   （交互式收集）
```

- **技能一/技能二并行独立**，无先后依赖，可同时执行。
- **技能三**消费技能一/二的产出 + WorkLoom 代码摸排（主事实源，PRD仅兜底背景），产出行业落地方案 + **平台能力反哺清单**（无法消化的优质内容→平台改进建议）。
- **技能四（delivery-config）**消费方案 + 客户授权，完成六槽装配、检查单、dry-run、审批激活。

## 二、技能清单与契约

| 技能 | 路径 | 输入 | 输出 |
|------|------|------|------|
| industry-benchmark-research | `skills/official/industry-entry/industry-benchmark-research/` | 目标行业+标杆企业 | 竞品脑暴文档（六维拆解+置信度分级） |
| industry-frontline-research | `skills/official/industry-entry/industry-frontline-research/` | 目标行业+客群+一线角色 | 一线作业调研文档（四层还原+AI替代矩阵+区间化测算） |
| workloom-industry-landing-design | `skills/official/industry-entry/workloom-industry-landing-design/` | 技能一/二产出+代码摸排 | 行业落地方案（六模块+反哺清单；无排期） |
| delivery-config | `skills/official/industry-entry/delivery-config/` | 落地方案+客户授权 | 激活的行业Bundle（行业定制版交付） |

## 三、共同纪律（各技能 SKILL.md 全文为准）

1. **图表渲染率100%**：交付物中所有 Mermaid 图必须实际渲染，一票否决。
2. **WorkLoom 能力引用必须经代码核验**：执行前动态读取最新代码（附录A读取清单），代码不可得时用兜底摘要并显著标注。
3. **时效性**：文档头部标注信息截止日期；竞品宣称数据 A/B/C 置信度分级。
4. **排期禁令**（技能三/四）：方案只输出任务与依赖，不输出任何工期/时间点；排期由研发团队独立决策。
5. **反哺闭环**：无法消化的内容汇入反哺清单，客户 opt-in 上报，团队侧 feedback-insight 技能每日聚类分析（见 `skills/official/product-feedback/feedback-insight/`）。
6. **迭代融合模式**：同一主题已有历史产出时，执行"对比→增补→融合"，产出融合版而非覆盖版。

## 四、与六装配槽的映射

技能三/四的产出最终落入 `bundles/<行业>/` 的六槽实物：档案Schema（一X一档）、对象与阶段枚举、工具集、围栏包、Agent班组preset、工作台UI。装配契约与起飞前检查单见 `packages/base/bundles/assembly.ts`。底座不预置任何行业词汇（红线）。
