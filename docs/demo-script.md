## 一、产品与客群深度分析

### 1.1 产品本质

WorkLoom 获客系统不是工具，是**一支住进商家通讯录的 AI 获客班组**：
- AI 视频内容工厂：脚本 → 渲染 → 审片 → 四平台 RPA 发布 → 回执复盘
- 闭环：选题 → 制作 → 分发 → 询盘 → 成交
- 人机权责：AI 提案、人拍板（围栏 + L4 人审 + 五元事件可追溯）

### 1.2 目标客群（首垂直：酒店）

| 客群 | 画像 | 最痛的点 | 买单动机 |
|---|---|---|---|
| 低星单体酒店业主（40-80 间房） | 夫妻店/小团队，无专职营销 | 没流量、询盘接不住、OTA 抽佣 15-25% | "有人帮我全天候搞流量，还比代运营便宜" |
| 民宿主 | 个人 IP 型，重内容但产能低 | 内容断更、多平台发不过来 | "一天一条视频还帮我发帮我回评论" |
| 小型连锁店长（3-10 家） | 有店长无总部 | 各店营销水平参差、看不见 ROI | "总部级营销中台，每家店都配得上" |

**尖叫公式** = 看得见的成交数字（归因到钱）× 不用操心的过程（AI 全包）× 我说了算的安全感（人拍板）

### 1.3 客户疑虑与剧本应答

| 疑虑 | 剧本中的应答场景 |
|---|---|
| "AI 做的内容能看吗" | 爆款复盘幕：12.6w 播放实拍+投产比 1:8.9 |
| "会不会乱报价/乱承诺" | L4 决策幕：协议价/券定价/线索出域必审，CEO 意见+依据链 |
| "数据是不是真的" | 归因幕：五元事件链 + 验链 + 全模拟运行态横幅（坦诚是演示数据） |
| "夜里谁接客" | 夜班幕：23 条询盘零漏接、语音前台凌晨 2 点接听 |

## 二、演示剧本（四幕，15-20 分钟）

### 序幕 · 震撼开场（昨日内容战报，30 秒）
- **台词**："昨天发了 4 条视频，播放 5.28 万，带货 ¥9,600——这条 12.6 万播放的爆款，从脚本到发布你没碰过一下。"
- **画面**：四平台发布回执 + 播放/GMV 数据 + 爆款复盘。

### 第一幕 · 班组在干活（经营主页 + 实况字幕，3 分钟）
- **台词**："你看，地板上是它的 16 个员工——AI 接待员 3 秒回询盘，内容 Agent 刚发了条亲子视频，渠道哨兵在盯竞对价格。底部这条字幕，是它实时在干的事。"
- **画面**：P0 地板剧场（云栖酒店品牌）+ 全中文实况字幕滚动（内容发布/询盘应答/竞对抓取/券推广）。
- **数据点**：1 工作中 · 2 请您定 · 13 待命。

### 第二幕 · 你拍板，它执行（L4 决策 + AskRail 对话，5 分钟）
- **台词**："¥88,000 的年度框架商单接不接、¥26,000 的母婴达人合不合作——它把单价、匹配度、预估播放都算好了摆在这，你点批准就签。"
- **画面**：首页 L4 决策卡 ×3 → 董事长视图请您决策 → 右侧 AskRail 剧本对话（"有什么要拍板的？"→ AI 列清单）。
- **关键**：AskRail 不是空的——首开即见店主与 AI 的完整经营对话（问询→审批→派单→复盘）。

### 第三幕 · 客户被接住了（C 端服务前台 + 夜班，4 分钟）
- **台词**："客人半夜 12 点问'含早餐吗能延迟退房吗'，它 3 秒就答了，还顺手备注了儿童洗漱用品送房。你睡着的时候，夜班接了 23 条询盘，一条没漏。"
- **画面**：C 端聊天历史（含早餐/延迟退房问答）→ 实操发消息秒回 → 夜班频道全中文行动流。

### 第四幕 · 算清每一块钱（归因复盘 + 董事长视图，3 分钟）
- **台词**："月底你只需要看这张表：每块钱从哪个入口来的、哪条内容带来的、哪个人跟进的——全在链上，可回放、可验真。"
- **画面**：月度归因战报事件 + 节拍控制台（晨报/偏差扫描/熔断巡检/董事会包）。

### 收尾 · 一句话
> "您只做三件事：定方向、拍板、收钱。其他的，班组全包。"

## 四、续写纪律

1. 新场景先进本文（剧本先行），再落数据；
2. 数字必须全链路一致（战报卡=事件=对话台词=种子注释），改一处全改；
3. 每个行业复制时，先写该行业的 demo-script，再写 seed-boost。
