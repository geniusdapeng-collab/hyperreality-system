# WorkLoom 视觉规范标准（Candy Design System v1.0）

> **适用**：所有使用 WorkLoom 底座的产品前端（PC 端 apps/web、C 端 apps/webc、移动端演示页、各行业 Bundle 经营剧场）。
> **事实源**：`apps/web/src/styles/tokens.css`（Tailwind v4 令牌制，只写 @theme）。一切颜色以令牌为准，禁止组件内硬编码品牌色。
> **定位**：小红书式糖果色——年轻、时尚、轻盈。深色星空时代（v1 深空蓝）已于 v3.4.0 终结。

---

## 一、设计原则

1. **轻盈第一**：浅底深字，信息靠层级不靠色块重量；内容再多也不显沉闷。
2. **一色一职**：珊瑚红=行动与奖励；蓝莓蓝=信息与证据；语义四色只做状态。禁止混用。
3. **对比即纪律**：文字/图标/人形在浅底上必须达到可读对比（正文 ≥4.5:1，辅文 ≥3:1，图形 ≥3:1）。**深色系元素（浅金、浅青、浅灰头身色）在浅底上一律加深一档**——本条由 D33 实战踩坑沉淀。
4. **圆角友好**：卡片 16px、气泡 14px、按钮全圆角；不用直角硬边。

## 二、色板（糖果色系）

### 2.1 背景四阶

| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-bg950` | `#fff5f7` | 页面底（奶莓） |
| `--color-bg900` | `#ffffff` | 卡片（云白） |
| `--color-bg800` | `#fff0f4` | 浮层/次级面板（蜜桃雾） |
| `--color-bg700` | `#ffe4ec` | 悬停/选中（樱花粉） |

### 2.2 品牌色

| 令牌 | 值 | 职责 |
|---|---|---|
| `--color-gold` | `#ff2442` | 主行动色（按钮/品牌/强调）· 珊瑚红 |
| `--color-gold2` | `#ff7a9e` | 渐变副色 · 糖果粉 |
| `--color-goldhi` | `#d4002a` | 深珊瑚：浅底上的强调文字/数字（原「高光」语义已反转为深阶） |
| `--color-ongold` | `#ffffff` | 主色上的文字 |
| `--color-holo` | `#4d96ff` | 信息/证据/链接 · 蓝莓蓝 |
| `--color-holo2` | `#6ec6ff` | 次级信息 · 天空蓝 |

### 2.3 语义四色（全局唯一，禁止另立）

| 令牌 | 值 | 语义 |
|---|---|---|
| `--color-go` | `#22c88a` | 薄荷绿：auto/已完成/通过 |
| `--color-warn` | `#ffaa33` | 蜜桃橙：review/待审/警告 |
| `--color-alert` | `#ff4d6d` | 草莓红：block/熔断/失败 |
| `--color-need` | `#b678ff` | 葡萄紫：需介入 |

### 2.4 文字三级

| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-ink` | `#33262b` | 正文（深可可） |
| `--color-ink2` | `#8a757d` | 辅助说明 |
| `--color-ink3` | `#b9a9b0` | 图例/占位（**禁止用于 12px 以下功能性文字**——D33 踩坑） |

### 2.5 描线与晕染

- `--color-line`: `rgb(255 36 66 / 0.14)` 卡片描边；`--color-gline`: `rgb(255 36 66 / 0.32)` 强调描边；
- `--color-nebula` `#ffe0ec` / `--color-nebula2` `#e8e0ff`：仅背景晕染与空态插画，不做功能色。

## 三、组件规范

### 3.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | `gold-grad`（135deg 珊瑚→糖果粉）+ 白字 + 全圆角 | 每屏最多 1-2 个主动作 |
| 次按钮 | `bg-card` + `border-gline` + `text-gold` | 次级动作 |
| 幽灵按钮 | `bg-bg800` + `text-ink2` | 辅助动作 |
| 危险按钮 | `border-alert` + `text-alert`（不用实底红） | 驳回/制动 |

### 3.2 卡片与标签

- 卡片：`bg-card` + `border-line` + `radius-panel`；强调卡加 `border-gline` 或左 3px 色条（分级：A=alert/B=gold/C=ink3）；
- 标签（tag）：`border` 圆角 999px + 10px 字号；hot=alert、gold=gold、teal=go 三色可选；
- 审批卡：左「◆ 待决断」warn 色 + 标题 + CEO 意见 + 命中门号 + 双按钮（批准 go 实底 / 驳回 alert 描边）。

### 3.3 表单与输入

- 输入框：`bg-card` + `border-line` + 全圆角 + `focus:border-gline`；
- 占位文字用 ink3，输入文字用 ink；错误提示用 alert，不用红底。

### 3.4 空态与横幅

- 空态：emoji 图标 + ink2 标题 + ink3 提示 + 次按钮行动点；
- 横幅（模拟态/告警）：浅琥珀底 `bg-amber-100/80` + `text-amber-800`（**禁止浅黄文字配浅黄底**——D33 踩坑）。

### 3.5 经营剧场（Floor Canvas）

- 地板主题由行业 Bundle `floor-scene.json` 提供（浅色系：酒店蜜桃/片场薰衣草/GEO 天空蓝），网格线用 `rgba(51,38,43,.07)`（**禁用白色网格线**）；
- 员工人形（SKIN）：working `#22c88a/#0e7a4a`、asking `#4d96ff/#2a6ac8`、blocked `#ffaa33/#c87a1a`、collab `#b678ff/#7a3ac8`、idle `#7a5c64/#4a383e`——**浅色系头身色在浅底上一律加深**（D33 踩坑）；
- 名牌：白底 88% + 深字 + 细描边（**禁用深底浅字泡**——浅底下会形成泥浆团）；
- 请示气泡：`#e8890c` 深蜜桃；CEO 名牌：`goldhi` 深珊瑚。

### 3.6 移动端

- 手机壳：页面 `bg-bg950`、卡片白、底部 tab 栏 `rgba(255,255,255,.96)` + 选中 gold；
- 演示页（docs/demo/*.html）与生产端共用同一色板值，禁止另起色名。

## 四、字体与动效

- 字体三级：sans 正文（PingFang/雅黑）/ mono 编号（JetBrains Mono，禁止换行）/ orb HUD 数字（Orbitron）；
- 字号阶梯：Display 44 / H1 22 / H2 16 / Body 13.5 / Caption 11 / Micro 10（不低于 9.5）；
- 动效：功能反馈 ≤1.2s；氛围类（漂移/呼吸/流光）全部登记 `prefers-reduced-motion` 降级；浅底下辉光类动效透明度减半（避免白雾感）。

## 五、历史踩坑纪律（每次改版前必读）

| 编号 | 教训 | 规则 |
|---|---|---|
| D33-1 | 深空色系直接换浅底后，浅金/浅青文字全灭 | 换主题先审「高光类」令牌——浅底上高光=深阶 |
| D33-2 | 员工人形浅灰头身色在浅地板上消失 | Canvas 精灵色系随主题复审，纯色验证法（先打纯红看渲染路径） |
| D33-3 | 深色名牌泡在浅底聚成泥浆团 | 浅底主题名牌=白底深字 |
| D33-4 | 琥珀横幅浅黄字配浅黄底不可读 | 语义横幅=浅底深字（amber-100 底 + amber-800 字） |
| D33-5 | 截图验收撞入场动画中途态被判「发白」 | 视觉验收截图必须等动画终态（virtual-time-budget ≥ 动画时长 ×2） |
| D33-6 | 「甲板/任务舱/航道管制台」舰队系黑话用户看不懂 | 产品文案禁用隐喻黑话：工作台/任务页/规则与权限 |

## 六、跨项目同步纪律

1. 令牌只改 `tokens.css`，组件只消费令牌——任何项目接到同步时，先比对 `tokens.css` 与本规范的 §二 色板；
2. 新项目接入：复制 `tokens.css` → 跑「纯色验证」（主色按钮/语义四色/文字三级各截一屏）→ 再走查组件；
3. 行业 Bundle 的 `floor-scene.json` 主题色必须从本规范 §3.5 的浅色域内选取；
4. 本文件变更需同步到：workloom / workloom-im / workloom-hotel / hyperreality-system 四仓 `docs/design-system.md`。
