# 行业落地向导（用户版）

> 装机完成后，WorkLoom 会主动引导你把它变成"你所在行业的定制版"。全程在主会话框内完成，无需技术人员。

## 这是什么

WorkLoom 是一套通用底座，不预置任何行业内容。「行业落地向导」是首次装机后的引导能力：你选择或输入所在行业，系统自动完成行业调研、方案设计、系统配置，最后交付一个为你行业定制的 WorkLoom。

## 两条通道

### 快速通道（已有行业，如服务业门店）

选择"服务业门店"等已支持行业 → 填写门店基础信息 → 绑定系统授权（门店管理系统/线上渠道账号、钉钉/企微等通知通道）→ 确认围栏阈值（只能调得更严）→ 审批激活。次日 08:30 收到第一份清晨决策包。

### 完整通道（新行业）

1. **说出你的行业**：主会话框输入（如"餐饮"），系统会追问澄清（正餐/快餐/茶饮？）。
2. **选择模式**：
   - **快速上线模式（默认）**：用内置行业骨架模板快速生成配置，先上线跑起来，之后再补深度调研。
   - **深度调研模式**：系统自动执行竞品调研与一线作业调研（两个任务并行），生成完整调研文档与落地方案，供你预览确认。
3. **交付配置**：系统把方案变成实际配置，过程中会请你逐项完成：基础信息填写、系统账号授权、围栏阈值确认。所有涉及钱和客户的动作，默认都需要你拍板。
4. **激活交付**：检查单全部通过后，你在审批卡片上确认激活——你的行业定制版即刻上线。

## 过程中你可能关心的

- **中断了怎么办**：随时可以暂停，下次继续，进度不丢。
- **没网/弱网**：可以用骨架模板先走通，联网后一键补跑调研。
- **免费版能用吗**：向导全程可用。激活时超出免费版范围的能力（夜班班组、巡检等）会显示"已配置·待升级解锁"，随时升级随时生效。
- **专家模式**：行业装配台支持跳过调研直接手写 Bundle，不进首次装机主路径。
- **"发送给WorkLoom团队"是什么**：配置中如果遇到 WorkLoom 暂时做不到的事，系统会询问你是否把这条"能力缺口"发送给WorkLoom团队（默认不发送；发送前你可以预览和编辑内容；只含能力描述，绝不含你的经营数据）。WorkLoom 团队每天自动汇总分析这些缺口，形成产品迭代建议——你的上报会直接推动产品进化。
